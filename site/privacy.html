Privacy Policy

Last updated: July 2, 2026

Our Commitment to Privacy

OpenReader is built from the ground up with privacy as a core principle. Your documents and data belong to you and stay under your control. We do not collect, sell, rent, or share your personal information or document contents with any third party.

Local-First Data Model

OpenReader is a desktop application that runs entirely on your device. All PDFs, annotations, highlights, search indexes, and settings are stored locally. No data is sent to any server. The application functions fully offline with no internet connection required.

You can export your settings and data at any time. The app does not transmit document content, usage patterns, or personally identifiable information over the network.

What We Collect

Nothing. OpenReader does not include analytics, telemetry, tracking pixels, or crash reporting. The app makes only the following network requests:

  • GitHub release check — An optional check against the GitHub API to detect new versions. This is triggered manually (Help → Check for Updates) and only reads a public API endpoint. No identifying information is sent.
  • Microsoft Store — If installed via the Store, standard Store telemetry and update services may apply as governed by Microsoft's privacy policy.

Third-Party Services

OpenReader is distributed through the Microsoft Store and GitHub Releases. When you download from these platforms, their respective privacy policies apply. See Microsoft's Privacy Statement and GitHub's Privacy Statement.

The OpenReader showcase website (reader.kovina.org) is hosted on Cloudflare Pages. Cloudflare may process standard HTTP request logs as part of their hosting service. We do not access or analyse these logs. See Cloudflare's Privacy Policy.

Data Deletion

All data is stored locally on your device. To delete it:

  • Settings/annotations: Clear the app data directory or uninstall the application.
  • PDF files: Delete the files from your file system. OpenReader does not copy or move your PDFs.
  • Search index: Delete the index directory in the app data folder, or use the Clear Search Index option in Settings.

Data Export

You can export your annotations, highlights, and search index at any time from the app's Settings panel. PDF files themselves remain on your file system and are never modified by OpenReader.

Changes to This Policy

If this policy changes materially, the "Last updated" date at the top will be revised. We will never reduce your privacy rights without notice.
